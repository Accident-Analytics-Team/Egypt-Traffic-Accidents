# README – Egypt Accident Analysis (2020–2024)

##  Project Overview :
The **Egypt Accident Analysis (2020–2024)** project aims to analyze real accident data across Egypt to identify key trends, patterns, and insights related to road safety.  
The goal is to transform raw data into meaningful visual stories through **Power BI dashboards** and a structured final presentation.

This project covers all major data analytics stages — from extraction and cleaning to visualization and storytelling — ensuring an end-to-end data-driven understanding of accident dynamics in Egypt.

---

## Data Overview :
The dataset used in this project represents **real data** collected from the **Central Agency for Public Mobilization and Statistics (CAPMAS)** — Egypt’s official statistics authority.  
It includes accident reports covering the years **2020 to 2024**, with information such as:

- Number of accidents, injuries, and deaths  
- Geographic distribution across Egyptian governorates  
- Yearly and monthly trends

The raw data was originally provided in **PDF format**, which required extraction, structuring, and cleaning before analysis.

## ⚙️ Data Processing :
The data extraction and processing phase involved multiple steps to transform the PDF-based datasets into a structured and analyzable format:

1. **Data Extraction**  
   - Accident data was extracted from official **CAPMAS PDF reports**.  
   - Tabular data was converted into **Excel files** using OCR and table recognition tools.

2. **Data Cleaning & Standardization**  
   - Removed missing or inconsistent values.  
   - Unified formats (e.g., date, numbers, text encoding).  
   - Ensured consistent naming conventions across years.

3. **Data Preparation**  
   - Aggregated and merged datasets by year and region.  
   - Added calculated columns for analysis (e.g., injury rate, death ratio).
